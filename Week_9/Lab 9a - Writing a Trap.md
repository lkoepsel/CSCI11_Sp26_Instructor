# Lab 9a - Writing a Trap

## Write a Trap to Toggle Case

Following the example, [How to Write a Trap Instruction](./HowtoWriteaTrapInstruction.md), write a trap which will toggle the case of a letter contained in R0. Be sure to use GETC and OUT in your example usage code to demonstrate the trap works as expected.

Be sure to write all three parts:
1. Initialize the trap vector
2. Trap execution code
3. Trap example usage
